# ۱۰. پرسش‌های متداول و رفع اشکال

[فهرست مستندات](../README.md) · [English](../en/10-faq.md) · **فارسی** · [→ مرجع API](09-api-reference.md)

**وقتی کلیک می‌کنم تقویم باز نمی‌شود.**
کنسول مرورگر را ببینید. دو علت رایج: فایل CSS اضافه نشده (پنجره هست ولی بدون استایل و ته صفحه پنهان است)، یا اسکریپت قبل از وجود `<input>` اجرا می‌شود؛ تگ `<script>` را بعد از input بگذارید یا در `DOMContentLoaded` اجرا کنید.

**تقویم پشت مودال / دیالوگ من باز می‌شود.**
`zIndex` را بالا ببرید یا پنجره را با `appendTo: '#my-modal'` داخل خود مودال بگذارید. داخل کانتینرهای دارای transform، `strategy: 'absolute'` را اضافه کنید.

**روی گوشی کیبورد صفحه تقویم را می‌پوشاند.**
نباید پیش بیاید؛ روی گوشی تقویم به‌صورت برگهٔ پایین باز می‌شود و کیبورد را بسته نگه می‌دارد (`suppressKeyboard: 'auto'`). اگر برگه را خاموش کرده‌اید، `suppressKeyboard: true` بگذارید.

**چطور یک تاریخ میلادی واقعی برای سرور بگیرم؟**
`picker.getValue('iso')` هر تقویمی که کاربر ببیند، `2026-05-28` می‌دهد. برای بازه: `picker.getRange()` را بگیرید و هر سر را قالب‌بندی کنید، یا `getValue('iso')` روی بازه `{ start, end }` برمی‌گرداند.

**چرا متن داخل کادر با ارقام انگلیسی است؟**
تا سرور، اعتبارسنج‌ها و اکسل بتوانند بخوانندش. با `inputDigits: 'fa'` عوضش کنید.

**تعطیلات نمایش داده نمی‌شوند.**
* بدون پیکربندی فقط تعطیلات ثابت شمسی و جمعه‌ها را دارید. روزهای مذهبی (قمری) داده می‌خواهند؛ [راهنمای ۴](04-holidays.md) را ببینید.
* هر سال وقتی کاربر آن را ببیند بارگذاری می‌شود. به `holidaysLoaded` / `holidaysError` گوش دهید.
* با `holidays: false` خاموش‌اند. با `highlightHolidays: false` رنگی نمی‌شوند.
* تقویم میلادی اصلاً تعطیلی داخلی ندارد.

**تقویم میلادی من دکمه‌های انگلیسی («Today»، «Clear») دارد.**
بستهٔ زبان را بارگذاری کنید (`izi-datepicker.locales.js` یا `import 'izi-datepicker/locales'`) یا کلمه‌های خودتان را با `iZiDatePicker.registerLocale` اضافه کنید.

**می‌توانم تاریخ‌های قبل از ۱۳۰۰ یا بعد از ۱۵۰۰ (شمسی) را به کار ببرم؟**
می‌توانید `minYear` / `maxYear` را بیشتر کنید، اما فقط ۱۳۰۰ تا ۱۵۰۰ با پیاده‌سازی‌های مرجع راستی‌آزمایی شده است. بیرون از آن، کتابخانه‌های مختلف در چند سال با هم اختلاف دارند.

**`setValue` مقدار `false` برمی‌گرداند.**
مقدار فهمیده نشد یا مجاز نیست (قبل از `minDate`، روز بسته، بیرون از سال‌ها، بازه‌ای که `minRangeDays` را نقض می‌کند ...). `onInvalidInput` را روشن کنید تا متن تایپ‌شدهٔ ناموفق را ببینید.

**با `setOptions` تقویم را عوض کردم و مقدار پاک شد.**
بله، عمداً: همان عددها در دو تقویم تاریخ‌های متفاوتی هستند. بعد از عوض کردن تقویم، دوباره مقدار بدهید.

**در صفحه دو تقویم دارم و کلیک روی یکی دیگری را می‌بندد.**
رفتار درست همین است: هر لحظه فقط یک پنجره باز است.

**چطور در React / Vue / Angular / Svelte استفاده کنم؟**
برای React و Vue بسته‌های آماده هست ([راهنمای ۸](08-frameworks-and-advanced.md)). برای بقیه از عنصر `<izi-datepicker>` استفاده کنید، یا تقویم را در hook مربوط به «mounted» بسازید و وقتی کامپوننت از بین می‌رود `destroy()` را صدا بزنید.

**روی کدام مرورگرها کار می‌کند؟**
Chrome/Edge، Firefox و Safari جدید باید کار کنند (به `Intl.DateTimeFormat`، ویژگی‌های منطقی CSS و `color-mix()` نیاز دارد). روی **Chromium** واقعاً تست شده است؛ Firefox، Safari و صفحه‌خوان‌های واقعی هنوز تست نشده‌اند و گزارش باگ بسیار ارزشمند است.

**حجمش چقدر است؟**
حدود ۳۷ کیلوبایت جاوااسکریپت و ۸ کیلوبایت CSS (gzip) با همهٔ قابلیت‌ها.

**باگ پیدا کردم / یک قابلیت می‌خواهم.**
یک [issue](https://github.com/yasproject/iZiDatePicker/issues/new/choose) باز کنید و گزینه‌ها و مرورگرتان را بنویسید. Pull request خوش‌آمد است: [CONTRIBUTING](../../CONTRIBUTING.md) را ببینید.
